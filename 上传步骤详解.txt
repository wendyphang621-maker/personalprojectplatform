==============================================
            GitHub Pages 上传步骤详解
==============================================

问题原因：之前上传的是源代码，不是构建后的静态文件

正确流程：
1. npm run build 构建项目
2. 上传 dist 文件夹内的文件（不是项目根目录的文件）

==============================================
步骤1：确认 dist 文件夹内容
==============================================

打开 E:\项目管理\dist 文件夹，里面应该有：
├── index.html          ← 必须上传
└── assets/             ← 必须上传（包含 JS 和 CSS）

绝对不要上传项目根目录的文件！

==============================================
步骤2：登录 GitHub
==============================================

访问：https://github.com/wendyphang621-maker/personalprojectplatform

==============================================
步骤3：切换到 gh-pages 分支
==============================================

在页面顶部，点击分支选择下拉菜单（默认显示 main）
输入 "gh-pages" 并选择

==============================================
步骤4：删除错误文件（关键！）
==============================================

当前 gh-pages 分支上可能有错误的文件：
- index.html（引用了 /src/main.js 的那个）
- src/ 文件夹
- 其他源代码文件

删除这些文件的方法：
1. 点击文件旁边的 trash 图标
2. 或者在上传新文件时自动覆盖

==============================================
步骤5：上传 dist 文件夹内的文件
==============================================

1. 点击 "Add file" → "Upload files"
2. 打开电脑上的 E:\项目管理\dist 文件夹
3. 按住 Ctrl 键，选中：
   - index.html
   - assets 文件夹
4. 将它们拖拽到 GitHub 的上传区域
5. 确保上传的是 dist 文件夹里面的内容，不是 dist 文件夹本身

==============================================
步骤6：提交更改
==============================================

1. 在页面底部填写提交信息，例如："部署新版本"
2. 点击 "Commit changes"

==============================================
步骤7：等待部署
==============================================

GitHub Pages 部署需要几分钟时间
不要急于刷新页面

==============================================
步骤8：访问验证
==============================================

访问地址：
https://wendyphang621-maker.github.io/personalprojectplatform/

如果页面未更新，按 Ctrl+F5 强制刷新

==============================================
常见错误排查
==============================================

错误1：页面空白
原因：上传了源代码，不是构建产物
解决：重新上传 dist 文件夹内的文件

错误2：CSS/JS 加载失败（404）
原因：路径配置不正确
解决：确保 base 配置正确

错误3：页面样式错乱
原因：缓存未刷新
解决：按 Ctrl+F5 强制刷新

错误4：Supabase 连接失败
原因：环境变量未配置
解决：在设置页面手动配置

==============================================
快速验证方法
==============================================

上传后，在浏览器地址栏输入：
https://wendyphang621-maker.github.io/personalprojectplatform/assets/index-Ck2fPsTg.css

如果能看到 CSS 内容，说明文件上传成功
如果显示 404，说明文件没有正确上传
