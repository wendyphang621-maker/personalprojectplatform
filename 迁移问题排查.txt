项目工作台 - 迁移问题排查指南
==============================================

一、常见启动问题
==============================================

问题1："node 不是内部或外部命令"
原因：未安装 Node.js 或未添加到系统 PATH
解决方案：
1. 访问 https://nodejs.org/ 下载并安装 Node.js
2. 安装完成后重新打开命令提示符

问题2：npm install 安装失败
原因：网络问题或缓存损坏
解决方案：
npm cache clean --force
npm install

问题3：端口 8080 被占用
原因：其他程序正在使用该端口
解决方案：
1. 查找占用端口的进程：netstat -ano | findstr :8080
2. 结束该进程：taskkill /PID <进程ID> /F
3. 或者修改 vite.config.js 中的端口号

问题4：页面空白或无法加载
原因：依赖缺失或构建失败
解决方案：
1. 确保 npm install 执行成功
2. 运行 npm run build 检查是否有构建错误
3. 检查浏览器控制台（F12）是否有报错信息

问题5：数据为空，页面显示空白列表
原因：Supabase 连接未配置或配置错误
解决方案：
1. 进入「设置」→「云端存储」
2. 配置正确的 Supabase URL 和 Anon Key
3. 点击「测试连接」确认配置正确

二、数据同步问题
==============================================

问题1：客户分组、寄样数据与旧电脑不一致
原因：两端连接了不同的数据库
解决方案：
1. 在「设置」页面检查 Supabase 配置
2. 确保新旧电脑使用相同的 URL 和 Key
3. 开启「强制使用线上正式库」开关

问题2：渲染素材库图片无法显示
原因：IndexedDB 缓存是浏览器本地数据，无法跨电脑迁移
解决方案：
1. 进入「机型档案」→「渲染图素材库」
2. 点击「选择文件夹」重新选择本地素材目录
3. 系统会重新解析并缓存到新电脑

三、Supabase 配置问题
==============================================

问题1：存储桶不存在
解决方案：
1. 在 Supabase Dashboard → Storage 中创建存储桶
2. 存储桶名称：customer-files（或 customer_light_files）
3. 访问权限设置为 Private

问题2：文件上传失败
原因：存储桶策略配置不正确
解决方案：
1. 在「设置」页面点击「创建存储桶」自动创建
2. 或者手动配置存储桶策略，允许 insert/update/delete/select

四、环境配置说明
==============================================

开发环境（localhost）：
- 默认使用用户在设置页面配置的 Supabase
- 可配置 VITE_DEV_SUPABASE_URL 作为默认值

生产环境（Netlify）：
- 自动使用 VITE_PROD_SUPABASE_URL 和 VITE_PROD_SUPABASE_ANON_KEY
- 需要在 Netlify 环境变量中配置
